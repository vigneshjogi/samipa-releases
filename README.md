# Samipa for Android

Samipa (समीप, "near") gives daily check-ins and medicine reminders for parents who live far from their children.

**Download the newest version:** [Samipa.apk](https://github.com/vigneshjogi/samipa-releases/releases/latest/download/Samipa.apk)

Or open https://samipa-app-2387a.web.app on the phone.

## Installing

1. Download the APK on the Android phone and open it.
2. If Android asks, allow installing apps from your browser.
3. Open Samipa. On a parent's phone choose "I'm the parent"; family members choose "I'm setting this up".

This repository holds only the installable app files. Each release lists what changed.
